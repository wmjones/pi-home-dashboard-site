Privacy Policy

Pi Home Dashboard · Last updated October 15, 2026

Pi Home Dashboard is a personal application used by a single household on its own Raspberry Pi. It is not offered to the public, has no user accounts of its own, and does not collect data from anyone outside the household.

Data the app accesses

  • Google Calendar: read-only access to the signed-in user's calendar events (titles, times, locations), used only to display them on the dashboard.
  • Spotify: the current playback state (track or episode, artist, progress, device), used to display it and to send play, pause and skip commands the user taps.
  • Todoist: the user's tasks and projects, used to display them and to mark tasks complete when the user taps them.

How data is stored and shared

  • Data is fetched directly from each service by software running on the household's Raspberry Pi and is held only in that device's memory and local cache.
  • Sign-in tokens are stored in a local file on that device and are never sent anywhere except to the service they belong to.
  • No data is sold, shared with third parties, used for advertising, or used to train machine-learning models.
  • The app has no analytics or tracking.

Google user data

Pi Home Dashboard's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from your Google Account permissions, Spotify account apps page, or Todoist's integration settings. Deleting the dashboard's local files removes all stored tokens and cached data.

Contact

Questions about this policy can be raised as an issue on this site's GitHub repository.
